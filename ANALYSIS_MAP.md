# Manuscript tables, figures, and corresponding code

This map accompanies the manuscript *Development and validation of an interpretable machine learning model for predicting mortality in elderly community-acquired pneumonia patients*. Start the analysis with [`scripts/run_analysis.py`](scripts/run_analysis.py). The manuscript settings are defined in [`config/paper.json`](config/paper.json). The files below are written to the directory specified by `--output-dir`. The [README](README.md) examples write to subdirectories of `outputs/` in the repository. Reproducing the baseline and missingness summaries requires the complete retrospective and prospective cohorts before screening and imputation.

The final model uses seven predictors, `ADL_admission`, `Neu`, `O_PSI`, `immunecompromised`, `Hb`, `eGFR_new`, and `Lym`. OOF refers to out-of-fold predictions in the training set.
